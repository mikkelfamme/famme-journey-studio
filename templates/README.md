# Journey Studio community templates

This folder is reserved for portable `.jstemplate` files that can be reviewed and shared through the public repository.

A contributed template should:

- be company-neutral and contain no confidential or personal data;
- include a clear name, description, category, semantic version, tags and author;
- use generic URLs or no URLs;
- avoid embedded proprietary creative assets;
- open successfully through **Templates → Import template** in Journey Studio.

## Suggested contribution flow

1. Build or edit a template in Journey Studio.
2. Use **Share** to export one `.jstemplate` file.
3. Add the file to this folder in a pull request.
4. Explain the intended use case and any assumptions in the pull request description.

Templates remain plain JSON under the hood so they are easy to review and version in Git.
