# RC12.9 — Readable node background colors

## What changed
- Nodes can now use one of six background colors: **White, Green, Yellow, Red, Blue or Gray**.
- The color is selected in **Node inspector → General → Background color**.
- Colors deliberately use soft tints rather than saturated fills, so titles, descriptions, icons, stage pills and signal badges stay readable.
- The selected color is stored as optional `backgroundTone` node data, so existing workspaces remain backward compatible and continue to default to white.
- The same color is shown in Editor, Template Editor, View/Presentation and Print/PDF.
- `.fjs`, `.jstemplate` and `.jsjourney` schemas are unchanged.

## Suggested use
- **White:** neutral/default
- **Green:** positive/approved/desired state
- **Yellow:** attention/review
- **Red:** blocker/risk/problem
- **Blue:** emphasis/information
- **Gray:** secondary/supporting step
