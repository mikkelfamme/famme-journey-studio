# RC12.10 — Master governance details & Insights data onboarding

## Master View
- Adds a clear explanation of what Master View is for across all journeys.
- Defines HEALTH, TODO, HANDOFF and % MAPPED directly on the page.
- Makes all four journey badges clickable.
- HEALTH opens the exact validation findings, severity and affected component.
- TODO opens unfinished node TODO annotations.
- HANDOFF opens cross-journey links with source, target and governance metadata.
- % MAPPED opens Direct / Proxy / Unmapped coverage and node-level mapping status.
- Clarifies that % MAPPED is data coverage, not a performance score.

## Insights & Data
- Adds a practical explanation of the purpose of the page.
- Documents the current local-first connection model: export stable IDs, map external data, import snapshots.
- Adds direct Performance-map and Actual-path-map export buttons.
- Adds direct Import Data access using the existing global preview/import flow.
- Explains Direct, Proxy and Unmapped mapping quality.
- Explains how Overview, Mapping Center, KPI Dictionary and Planned vs Actual should be used.
- Clarifies that Journey Studio does not currently maintain a live backend connection to GA4, Google Ads, Meta, BigQuery or CRM.

## Compatibility
- No workspace, database or portable-file schema changes.
- Existing journeys, templates, components and imported snapshots remain compatible.
