# RC12.3 — Desktop shortcut flow

- Restores **Create desktop shortcut** in Settings for installed Journey Studio PWAs.
- No `.url` / `.download` shortcut is generated.
- The action opens the Edge installed-app manager and copies `edge://apps` as a fallback.
- The modal explains: Journey Studio → Details → Create desktop shortcut.
- Keeps the installed PWA identity, JS icon assets, workspace schema and local data unchanged.
