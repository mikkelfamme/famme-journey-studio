# RC12.10.1 — Master View build hotfix

- Fixes the GitHub Actions TypeScript errors in `src/features/journeys/MasterView.tsx`.

- The component now captures the narrowed value as `currentWorkspace` and uses that reference throughout the render and nested detail logic.

- No changes to workspace, IndexedDB, `.fjs`, `.jstemplate`, `.jsjourney`, performance snapshot or actual-path schemas.
