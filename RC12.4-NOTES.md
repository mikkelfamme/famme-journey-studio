# RC12.4 — Browser-aware desktop shortcuts

- Settings → Create desktop shortcut now detects the active browser.
- Chrome uses `chrome://apps`; Edge uses `edge://apps`; Brave uses `brave://apps`; Opera/Vivaldi use their own app-manager addresses.
- Browsers without a known app-manager route get generic installed-app instructions.
- A universal Windows fallback copies `shell:AppsFolder`, which works independently of the browser used to install Journey Studio.
- Journey Studio never generates `.url` or `.download` shortcuts.
