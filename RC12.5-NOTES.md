# RC12.5 — Premium animated journey flow

This visual hotfix restores the more polished sense of movement in Journey Studio without changing journey data.

- All live journey connections use clearer arrowheads and higher-contrast strokes.
- Connections use a restrained directional dash animation.
- Hover, selected and active-path states become stronger and easier to follow.
- Edge labels use clearer text/background contrast.
- Editor, Template Editor, View and Presentation Mode share the same visual language.
- Reduced-motion preferences disable the animation automatically.
