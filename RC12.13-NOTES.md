# RC12.13 — Switchable funnel orientation

- Adds per-journey Horizontal / Vertical funnel orientation.
- Switching orientation reflows the same nodes and connections instead of creating a copy.
- Tidy, stage guardrails, View, Presentation, SVG, PNG and Print/PDF follow the selected orientation.
- Orientation is persisted in workspace, .jsjourney, templates and version snapshots.
- Existing journeys default to Horizontal for backward compatibility.
