# RC12.7 — Clearer component types

## What changed
- Renamed **Type** to **Component type** in the node inspector.
- Grouped component types by Customer, Channels, Experience, Outcomes and Lifecycle.
- Added a concise explanation under the component-type selector.
- Added three backwards-compatible component types:
  - Audience / segment
  - Shop / checkout
  - Physical visit
- Added icons, print styling, palette support and legacy normalization for the new types.
- Existing workspace schemas and database keys are unchanged.
