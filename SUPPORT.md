# Support

For reproducible bugs and public feature requests, use the repository issue templates.

Before reporting a bug:

1. Export a backup of the workspace if possible.
2. Reload the app and check Recovery in Settings if the problem concerns local state.
3. Confirm the current application version in About.
4. Reproduce the issue in the generic demo workspace when possible.

Do not upload confidential or company-sensitive workspace files to a public issue.
