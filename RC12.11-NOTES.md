# RC12.11 — Clean routing, compact tracking & custom components

- Smarter Tidy: preserves relative order, increases vertical clearance and redistributes ports to reduce edge collisions.
- One routing model across Editor, View, SVG/PNG and Print/PDF, including separate lanes for fan-out and fan-in routes.
- Export/print uses saved node dimensions when available instead of forcing every component into the same box size.
- Added ChatGPT under Channels.
- Added compact Tracking point components for inline measurement/sales events between larger journey steps.
- Added direct attached connections without arrowheads for adjacent components; adjacent new connections default to this style.
- Added full create/edit Component Library editor with editable component metadata, type, stage, color, copy, URL, tracking, creatives and notes.

Compatibility: workspace, .fjs, .jsjourney and .jstemplate schemas are unchanged. New fields/types are additive and normalized by existing import logic.
