# RC12 — Template Studio, sharing & presentation

## Highlights

- Custom templates are created blank.
- System and custom templates can be edited in a dedicated Template Editor.
- Template Gallery supports preview, metadata, version/tags/author, individual share/import, and import preview before adding a file.
- One journey can be exported/imported as `.jsjourney`.
- View and Editor can export SVG/PNG.
- View includes a clean fullscreen Presentation Mode with Previous/Next navigation and node details.
- Command Palette searches nodes, tracking, creatives and URLs across journeys.
- Stage guardrails flag nodes positioned outside their assigned funnel stage.
- Public repository includes `/templates` for community-contributed `.jstemplate` files.

No workspace schema version bump is required. Missing template metadata is migrated at load time.
