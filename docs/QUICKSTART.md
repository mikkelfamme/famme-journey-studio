# Quick start

## 1. Create or open a workspace

Start blank, load the synthetic demo, or import a `.fjs` workspace. Imports are previewed before they change local data.

## 2. Create a journey

Open **Journeys**, choose a template and create an independent journey. Use the visual editor to connect customer intent, channels, pages, tracking and outcomes.

## 3. Reuse architecture

- **Templates** create independent full-journey copies.
- **Component Library** creates reusable linked node definitions that can be synchronized across journeys.

## 4. Add intelligence data

Use **Insights & Data** to import performance and actual-path snapshots. Mapping quality and KPI semantics live in the workspace; imported data remains a linked layer.

## 5. Share safely

Use **Share & Portfolio** for a full portable workspace or a sanitized portfolio copy.

## Productivity

- `Ctrl/Cmd + K`: command palette
- `?`: contextual help
- `Ctrl/Cmd + S`: save
- `Ctrl/Cmd + Z`: undo in the journey editor
- `Ctrl/Cmd + Y` or `Ctrl/Cmd + Shift + Z`: redo
