# RC12.2 — PWA identity and Windows shortcut correction

This release separates the real installable PWA from Windows Internet Shortcut files.

- Installed app name: **Journey Studio**
- In-app product name: **Journey Studio by Famme**
- App icon: **JS**
- New stable PWA manifest identity prevents Chromium/Windows from reusing the original F app identity.
- New versioned icon URLs and manifest filename break stale icon caches.
- Settings includes a dedicated App installation card using the browser's real PWA install prompt.
- Journey Studio does not generate `.url` / `.download` Internet Shortcut files.

Existing workspaces are unaffected. Users with an older F-branded installation should uninstall that PWA once, refresh the public site, and install Journey Studio again.
