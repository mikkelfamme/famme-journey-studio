# RC12.2 — Blank first journeys & desktop shortcut helper

## Changes

- **New journey is blank by default.** The top-bar New journey action creates zero nodes and zero connections.
- **Create from template defaults to Blank journey.** Existing built-in and custom templates remain available when a predefined structure is explicitly selected.
- **Settings gets Desktop app & shortcut controls.** The native PWA install prompt is exposed when available.
- **Windows shortcut helper.** On Chromium browsers that support the File System Access API, Journey Studio opens Save As and lets the user save `Journey Studio.url` directly to Desktop. Other browsers fall back to downloading the shortcut file.
- The shortcut points to the deployed Journey Studio URL and references the JS-branded icon asset.

### Platform limitation

A browser-installed PWA is not allowed to silently create a Windows `.lnk` file in the Desktop folder. A guaranteed native Windows shortcut without a save dialog would require a packaged desktop installer (for example Electron/Tauri/MSIX).
