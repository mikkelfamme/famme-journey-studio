# Famme Journey Studio 2.0.0-rc.3

## Journey Editor polish

RC3 focuses on the primary working surface of Famme Journey Studio. The editor now prioritizes visual hierarchy, speed and calmness rather than adding another feature layer.

### Highlights

- Searchable, grouped component palette.
- Collapsible left palette and right inspector.
- Redesigned journey nodes with type icons, stage pills and quieter handles.
- Stronger selected and hover states without visual noise.
- Cleaner toolbar with explicit saved/unsaved state.
- More compact review actions and better canvas use.
- Refined node inspector with icon tabs, counters and two-column Type/Stage fields.
- Improved connection and selection visuals.

### Product principle

The editor should remain visually polished while still supporting dense, professional journey architecture work.
