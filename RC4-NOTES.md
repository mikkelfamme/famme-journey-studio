# Famme Journey Studio 2.0.0-rc.4

## Editor UX & compact flow

RC4 focuses on making large journeys easier to understand and faster to edit.

### Highlights

- **Tidy** places nodes into compact funnel-stage columns while retaining graph relationships.
- **Fit** frames the whole journey without manual zooming.
- Funnel stages are visible as subtle canvas zones: Discovery, Consideration, Action and Lifecycle.
- Selecting a node highlights its connected journey path and fades unrelated architecture.
- The inspector stays out of the way until a node, edge or review surface needs it.
- Review tools are consolidated into one menu so the main toolbar stays focused on editing.
- Selected nodes expose lightweight duplicate/delete quick actions.
- Node scale and typography are tuned for large desktop canvases.
