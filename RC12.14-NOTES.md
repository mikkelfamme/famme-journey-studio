# RC12.14 - Bidirectional connection ports

## What changed

- Every visible connection point on a component can both send and receive an arrow.
- The existing 3 top, 2 left, 3 bottom and 2 right ports are retained.
- Editors use React Flow loose connection mode so the nominal source/target role no longer restricts interaction.
- Saved opposite-role ports are preserved instead of being remapped during normalization.
- Tidy and export routing can choose from all ten physical ports for both edge endpoints.
- Existing .fjs, .jsjourney and .jstemplate files remain backward compatible.
