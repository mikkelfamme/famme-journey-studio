# RC12.6 — Real Windows desktop shortcut helper

This release implements the native-helper route for Windows desktop shortcuts.

## What changed
- Settings no longer sends users to `chrome://apps`, `edge://apps` or `shell:AppsFolder` as the primary shortcut flow.
- A one-time Windows helper installer is published with the app at `public/windows-helper/Install-Journey-Studio-Helper.vbs`.
- The helper installs only inside the current user's profile and registers `journeystudio-helper://` under HKCU.
- The Settings action `Create desktop shortcut` calls `journeystudio-helper://create-shortcut`.
- The helper searches the user's/common Start menu for the installed Journey Studio PWA shortcut, copies that real `.lnk` to the desktop, and applies the JS icon.
- No PowerShell and no administrator rights are required.
- A ZIP fallback is included if direct VBS downloads are blocked by the browser.

## First-use flow
1. Install Journey Studio as a PWA/app.
2. Settings > Create desktop shortcut.
3. Download the Windows helper once.
4. Double-click `Install-Journey-Studio-Helper.vbs`.
5. A correct `Journey Studio.lnk` is created immediately.
6. Later, Settings > Create desktop shortcut can recreate it with one click.

## Corporate policy note
Some managed Windows environments disable Windows Script Host (`.vbs`). If that policy is enabled, the helper will not run and a compiled native helper would be required instead.
