# RC12.12 — Correct arrow entry & collision-aware lanes

- Fixed the compound-handle parsing bug that treated `target-top-left` as a left-side port and `source-bottom-left` as a left-side port.
- Reworked mixed orthogonal routing so the last segment always approaches the target perpendicular to the target edge: top = downward into the node, left = rightward into the node.
- Route simplification now preserves deliberate reverse approach stubs instead of collapsing them into a wrongly directed final segment.
- Tidy distributes sibling connections across distinct ports using geometry: sources clearly above favour top target ports; level/left sources favour left target ports.
- Route lane selection is collision-aware and searches alternate corridors to avoid long parallel overlaps. Crossings remain allowed.
- Static SVG/PNG and Print/PDF use redistributed ports plus the same collision-aware lanes for clearer exports.

Compatibility: workspace, `.fjs`, `.jsjourney`, `.jstemplate`, performance and actual-path schemas are unchanged.
