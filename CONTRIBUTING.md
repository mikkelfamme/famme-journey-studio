# Contributing

Famme Journey Studio is currently in early public-core development.

1. Fork the repository.
2. Create a feature branch.
3. Keep application code generic and free of private company data.
4. Run `npm run typecheck` and `npm run build` before opening a pull request.
5. Describe any workspace schema change explicitly.

Please do not include private customer, employer, campaign, analytics or tracking data in issues, pull requests or fixtures.
